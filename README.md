# الأستاذ — لوحة يامن

موقع شخصي بسيط: الجدول، التقويم، المواد، والملخصات.
صفحة ثابتة — تشتغل على GitHub Pages بدون أي سيرفر.

## النشر على GitHub Pages

1. ارفع محتوى هذا المجلد إلى المستودع (repo).
2. **Settings → Pages → Source: Deploy from a branch → main / (root)**
3. بعد دقيقة يصير الرابط: `https://<username>.github.io/<repo>/`

> المستودع ممكن يكون **private**، لكن صفحة Pages نفسها تكون عامة على الحساب المجاني.
> ما فيه شي حسّاس هنا — جدول ومواعيد فقط.

## التعديل

كل البيانات في ملف واحد: **`data.js`**

| المتغير | وش فيه |
|---|---|
| `STUDENT` | الاسم، الرقم، المعدل، الساعات |
| `TERM` | بداية ونهاية الفصل + الشهور المعروضة في التقويم |
| `COURSES` | المواد الخمس — الدكتور، القاعة، اللون |
| `SCHEDULE` | الجدول الأسبوعي (`day`: 0=الأحد … 4=الخميس) |
| `DEADLINES` | الاختبارات والواجبات والمواعيد الجامعية |
| `HOLIDAYS` | الإجازات |
| `GRADING` | توزيع الدرجات لكل مادة |
| `MKT231_WEEKS` | خطة سلوك المستهلك أسبوعاً بأسبوع |
| `ABSENCE` | عدد الغيابات — حدّثه أول بأول |
| `LESSONS` | الملخصات في مجلد `lessons/` |

### إضافة موعد جديد

```js
{ date:"2026-11-03", code:"MGT 102", title:"كويز ١", kind:"exam", weight:10,
  note:"يغطي الفصول ١–٣" }
```

احفظ الملف، ارفعه، وبيظهر في التقويم وفي "أقرب المواعيد" تلقائياً.

## ملاحظات

- **`index.html` لازم يكون جنب `data.js`.** لو فتحته لحاله بدون الملف، الصفحة تطلع فاضية.
- التقويم يعرض من أغسطس ٢٠٢٦ إلى يناير ٢٠٢٧ — غيّر `TERM.months` لتمديده.
- الصفحة تدعم الوضع الليلي تلقائياً حسب إعداد الجهاز.
